# /design

Invoke the `ui-ux-designer` subagent and the `ui-ux-design-system` skill.

## Phased Workflow

1. **Phase 1: Visual Direction & Token Definition**
   - Establish color scheme (60-30-10 rule), typography scale, border radii, and dark/light elevation tokens.
2. **Phase 2: Component Architecture**
   - Structure responsive layout, padding hierarchy, and container boundaries using semantic HTML.
3. **Phase 3: Micro-Interactions & Styling**
   - Apply Tailwind CSS / CSS custom properties, backdrop blur, border highlights, and cubic-bezier transition states.
4. **Phase 4: Accessibility & Verification**
   - Check contrast ratio (WCAG 2.2 AAA), visible focus states, and keyboard navigation.
